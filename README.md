# TODO.txt

Backlog des améliorations de l'émission **CuistOps**. Un seul board, des labels par domaine.

## Convention

| Label | Sens |
|---|---|
| `area:ideas` | idées, backlog, capture |
| `area:veille` | veille et recherche de sujets |
| `area:highlights` | clips, highlights, YouTube |
| `area:overlays` | overlays OBS, UI, scènes |
| `area:live-infra` | streaming, encodage, diffusion |
| `area:security` | secrets, credentials, rotation |
| `priority:now` | à faire pendant ou juste après le live |
| `priority:next` | prochaine session |
| `priority:later` | quand le reste est stable |
| `research:done` | passe de veille open source déjà faite |
| `needs:decision` | attend un choix de Quentin |
| `size:S` / `M` / `L` | moins d'une demi-journée / une journée / plusieurs jours |

## Repos concernés

- [qjoly/cuistops-overlays](https://github.com/qjoly/cuistops-overlays) — overlays OBS (privé)
- [CuistOps/cuistdex](https://github.com/CuistOps/cuistdex) — catalogue des produits passés à la casserole

## Règle

Une issue n'est fermée que lorsque son **critère de done** est vérifié pour de vrai, pas quand le code est écrit.
